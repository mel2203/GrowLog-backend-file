Welcome to GrowLog API!

GrowLog is a plant care API that holds database on how to care for your plants, created by Lyana

How to use paths?

PLANTS

GET /plants

Add /plants at the end of your url to retrieve all plants in the database and their info

GET /plants/:id

Returns one plant that matches id, 400 if id is not a number and 404 if id not found

POST /plants

use /post to add new plants to the database. If a field is missing a 400 error will appear

{
  "name": "Lavender",
  "care_needs": "Full sun. Water sparingly.",
  "instructions": "Let the soil dry between waterings.",
  "author_id": 3,
  "category_id": 2
  "image_url": (insert your image)
}

USERS

GET /users

Returns all users that are using GrowLog.

GET /users/:id

Returns one user. Returns 400 if the id is not a number and 404 if the user is not found.

POST /users

Creates a user. Returns 201 on success, 400 if username is missing and 409 if the username is taken.

{
  "username": "cactus_carla"
}

Categories

GET /categories

Returns all categories.

GET /categories/:id

Returns one category. Returns 400 if the id is not a number and 404 if the category is not found.

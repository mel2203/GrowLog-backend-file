# 🌿 GrowLog

 **Welcome to GrowLog. A plant care guide, shared by gardeners.** 🌱

 This is the **frontend** of GrowLog, built with React. It talks to the GrowLog API (see the backend repo).

## 📡 API endpoints
| Method | Route | What it does |
|---|---|---|
| GET | `/plants` | Get all plants |
| GET | `/plants/:id` | Get one plant |
| POST | `/plants` | Add a plant |
| GET | `/users` | Get all gardeners |
| POST | `/users` | Add a gardener |
| GET | `/categories` | Get all categories |
